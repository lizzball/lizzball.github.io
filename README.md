# Elizabeth Ball — Science, Data & Context

A responsive, editorial research portfolio for Elizabeth Ball, MSc, with a visual language inspired by [Veyra](https://veyrainsights.com/).

## Website

**https://lizzball.github.io/** — available once GitHub Pages is enabled for this repository.

The site includes:
- A homepage featuring selected research and applied machine-learning work
- Individual case studies for endometriosis, thyroid eye disease, terminal reliability and a synthetic diagnostic laboratory
- A field note on signal, noise and research interpretation
- Original SVG artwork, responsive styling, accessible navigation and smooth scrolling

## Publishing

In this repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then **main** and **/(root)**; save. GitHub will publish the static HTML site at the URL above.

No build step or JavaScript framework is required. The website's entry point is `index.html`.

## Edit

- `index.html`: homepage content
- `projects/`: case studies
- `notes/`: essays / field notes
- `styles.css`: layout, typography and Veyra-inspired palette
- `script.js`: navigation and reveal effects
- `assets/`: original SVG illustrations

These examples use public or synthetic data and are **not validated clinical diagnostics or deployed commercial models**. See the linked repositories for methodological details and limitations.
